# DevOps & Automation Lab 🚀

Repositório dedicado ao desenvolvimento de práticas, automações e estudos voltados para a cultura DevOps e Infraestrutura como Código (IaC).

---

## 📌 Objetivo do Projeto

Centralizar scripts de automação, laboratórios de configuração de servidores e estudos práticos de ferramentas essenciais para ambientes em nuvem e infraestrutura moderna.

---

## 🛠️ Tecnologias & Ferramentas

* **Sistema Operacional:** Linux (Ubuntu / WSL)
* **Controle de Versão:** Git & GitHub
* **Automação & Scripting:** Bash / Shell Script & Python
* **Infraestrutura como Código (IaC):** Terraform & Ansible
* **Contêineres:** Docker

---

```text
├── docs/           # Anotações e documentação técnica
